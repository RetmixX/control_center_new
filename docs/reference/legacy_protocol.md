# Протокол ControlCenter 2.0.x (восстановлен из ControlCenter.exe)

Исходник: `ControlCenter.exe` — PyInstaller, Python 3.11, PyQt5. Модули: `ControlCenter`, `Gui`, `EquipmentData`,
`NodeRedData`, `UDPData`, `UDP_Messager`, `SetTeamFile`, `getThemeByOS`. Байткод разобран через `dis` (pycdc
полностью не декомпилирует 3.11). Здесь — то, на чём основана совместимость версии 3.

## Node-RED

- `ws://<IP команды>:8765` — клиент QWebSocket, приходят JSON-команды IOT Function.
- `ws://<IP команды>:8766` — клиент QWebSocket, уходит обратная связь.
- 2.0 читал ключи команды **по позиции** (`list(data.items())[i]`) в порядке
  robot_name, N, X, Y, T, G, V, D0, L1, L2, L3, L4, P, Text. Версия 3 читает по имени.
- Ошибка 471, если нет robot_name; 570, если имени нет в списке устройств команды.
- Имя устройства: `polygonName.split('_')` -> `parts[0] + str(teamIndex+1) + '_' + parts[1]`.
- Block Resending: команда не отправляется, если совпадает с предыдущей для этого устройства.
- Ручное управление недоступно, пока подключён Node-RED.

## Команды на оборудование (UDP, порт из _PolygonData.csv, обычно 8888)

| Ключ | Режим | Сообщение |
|---|---|---|
| P1 паллетайзер | координаты | `p:X:Y:G:V#` |
| P1 | позиция | X = номер точки из `_Pallitizer.csv` -> `p:X:Y:Z:V#` |
| M угловой | координаты | `g:X:Y:T:G:V#` |
| M1 промышленный | координаты | `g:X:Y:T:G:V:V:V:V#` |
| T светофор | — | `l:L1:L4:L3:L2#` (порядок именно такой) |
| C конвейер | — | `s:N:P#` |
| SC смарт-камера | — | G=1 -> `c:2#`, G=0 -> `c:1#`, G=-1 -> `c:0#` |
| R2 терминал | — | `r:L1:L2:L3:L4:P:TEXT#` (пустой TEXT — пустой дисплей) |

Text = `Start`: P1 -> `p:220:0:180:0#`, M -> `1#`, M1 -> `g:390:-175.5:0:376:0:0:0:0#`.
Text = `Parking`: P1/M -> `2#`, M1 -> как Start. Иначе ошибка 473.
Кнопки Special Activity: `r`/`s` — включить/выключить обратную связь устройства, `1`/`2`/`3` — Start/Parking/Relax.
Для C кнопка `1` отправляла последовательность `s:0:1#`, `s:1:1#`, `s:0:1#`.

## Обратная связь от оборудования (UDP -> 8888), строки `TYPE:id:...#`, id = STATE

| TYPE | Поля |
|---|---|
| M | s=[2], n=[3], m1..m6=[4..9] (float) |
| T | s, n, t1..t6 (int) |
| L | s, n, l1..l6 (int) |
| R | s=0, p=[2], b1..b3=[3..5] |
| E | e1..e6=[4..9] |
| C | n=[2], l1..l6=[3..8] (строки; эмулятор 2.0 так генерировал данные **SC-камеры**: n 0..100, l 1..6) |
| B1 | s=0, d1..d3=[2..4] |
| BR | s=[2] |

При каждом входящем UDP-пакете 2.0 рассылал в :8766 обратную связь по **всем** устройствам:
`{"name", "n","s","m1..m6","t1..t6","l0..l6","b1..b3","p","e1..e6","d1..d3"}`.
